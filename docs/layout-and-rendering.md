# 布局与渲染

`level2` Transform269 与 `level3` Transform3674 的 `MessageDialog/MessageText` 使用本地Y=-12，为中文正文保留上边距。它们与 `MapTitleLabel` 的位置无关。

`sharedassets0.assets` Material5 使用原版基准队列3000。`CW3Rendering` 为各面板的材质副本按面板、子层级Z和widget depth排序，并同步裁切材质队列；不要统一提高所有文字的队列。

NGUI的动态字体序列化绑定及两份嵌入Sans字体保留。前者使材质/图集与动态字体一致，后者为受控外部字体不可用时保留中文覆盖。样式隔离使用控件侧的UIFont副本，不修改共享原生UIFont。

默认字号和控件位置保持既有行为。可选字体与字号配置见[字体与字号](text-style.md)。


## 地图编辑器显示边界

窗口标题由 `GUIUtils.MyWindow` 的标题 Label 消费，使用独立样式副本；原有 BeginArea、回调和关闭逻辑保留。枚举选项中的 TextField 只有在返回值立即丢弃时才作为显示目标；可写名称、脚本、内部键和序列化值保持原文。编辑器竖排标签按原控件身份组成“地形”和“单位”，不改点击接收者。

新增绑定以固定原版 IL/资源身份、显示消费链和反向 IL 校验为依据。消费链契约检查可写输入及地址逃逸拒绝；画面、输入、纹理关闭、尺寸取消及重入另做定向验证。若固定原版指纹或消费链改变，绑定须重新审计。

### 本地字体的自动加载

Unity 5.2 无裸字体字节 setter；本地静态字体由 C# 填入固定 Windows/5.2.3 的原生 Font 容器。封装采用已验证的 UnityRaw v3、serialized15、完整类型身份和数组标记；材质指向外部内置 Font Shader，包含预载引用。动态标记为 -2，字形和图集由 Unity 管理；不再维护静态字号模板、GDI 字图或 UIFont 字形调用适配。

模板只包含版本锁定的元数据和空白字体/材质/纹理对象，不含用户或系统字体数据。运行时仅填写源字节、名称、度量及对象长度/偏移；独立解析器约束 C# 输出。缓存按字体内容和模板版本生成，完整校验后原子写入；失败按控件回退。容器卸载时保留已载入 Font，Font 与材质跨场景持有，图集重建沿既有事件刷新控件和像素采样；退出时释放。源变化重启生效，不增加热切换生命周期。

实际画面、NGUI/图集/重入和真实输入分别验收；CrossOver 结果不代替原生 Windows。可撤销方式为改回 `sans` 或移走本地字体并重启；安装恢复仍受版本、哈希及恢复点约束。

### 字体设置页

设置入口是原 SettingsPanel／MenuPanel 下独立的碰撞器，位于原 308px 背景下方，中心距离底边 19px、按钮高 30px，保留 4px 间隔。显示矩形由同一碰撞器经原 UI 相机投影，避免文字与点击区域使用不同坐标。主菜单和游戏菜单复用同一设置事务，不改原标签页、关闭回调或地图数据。

打开时暂存并禁用原 UICamera，同时占用原焦点标志；关闭后待点击／Escape 释放再恢复，场景切换也清理。配置只在保存时原子替换，取消与默认草稿不写文件；保存成功后在下一次 LateUpdate 一次性更新字号，复用原始尺寸与角色；UILabel 原生 MarkAsChanged 清除文本缓存，TextMesh 保留已绘制文本和原角色，IMGUI 下次布局读取活动策略。取消与默认草稿不触发刷新；字体和像素基准改动仍在重启后加载。独立不透明背景防止原设置页透出。构建版本由现有 patch_version 生成进实际加载 DLL。

放大字号时，正文按原对话框的按钮行位置预留 4px，用原字体换行测量完整文本，最低缩至 12px；主菜单 EntryPoints 的 TextMesh 按原父碰撞器宽高适配，像素字体只按整倍数递减。锚点、按钮行和点击范围不变。字号复用原始尺寸，适配后的实际尺寸单独记忆，避免反复保存累乘。极长未见文本的最小字号边界不保证完全容纳。

IMGUI 显示包装只在字体或字号确有差异时复制 GUIStyle；已有显式代码输入样式、加载失败和参数一致时复用调用方样式。仍保留原生调用、矩形、焦点与控件 ID，不增加跨控件缓存。


像素标题（CharacterName / MapTitleLabel）沿用 TextStyles 已按有效像素基准对齐的尺寸，不再由标题布局无条件写回 16×百分比；宽度不足时按整基准递减，最低保留一倍。Fitted 将标题 UIFont 字形大小同步到适配后的整数尺寸，避免较大栅格二次缩放。普通字体与非像素缺字回退沿用原 16px / 12px 百分比规则，标题行数、宽度、原生锚点规则与点击区域不变。TextStyleContracts 联测首次应用、重复处理、字号热改、显式/注册像素基准、缺字回退及长转短；该契约只模拟宿主度量，不证明实际字体栅格、画面或输入。最低一倍仍不能保证极长标题完整容纳；可撤销为标题改回无像素基准的 sans 并重启。

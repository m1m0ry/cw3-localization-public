# 布局与渲染

## 基础布局与材质排序

- **对话框边距**：`level2` Transform269 与 `level3` Transform3674 的 `MessageDialog/MessageText` 使用本地坐标 Y=-12，为中文正文留出上边距，且不影响 `MapTitleLabel` 的位置。
- **渲染队列**：`sharedassets0.assets` Material5 保持原版基准队列 3000。`CW3Rendering` 按面板、子层级 Z 和 widget depth 对各面板的材质副本排序，并同步裁切材质队列；不要统一提高所有文字的渲染队列。
- **字体绑定与样式隔离**：保留 NGUI 动态字体序列化绑定（使材质/图集与动态字体一致）及两份嵌入 Sans 字体（在外部字体不可用时提供中文兜底）。样式隔离通过控件侧的 `UIFont` 副本实现，不修改共享的原生 `UIFont`。

默认字号和控件位置保持既有行为。可选的字体与字号设置见[字体与字号](text-style.md)。

## 地图编辑器显示边界

- **控件消费与隔离**：窗口标题由 `GUIUtils.MyWindow` 的标题 Label 消费并使用独立样式副本，保留原有的 BeginArea、回调和关闭逻辑。枚举选项中的 TextField 仅在返回值立即丢弃时作为显示目标；可写名称、脚本、内部键和序列化值保持原文。编辑器竖排标签按原控件身份组合为“地形”和“单位”，不改变点击接收者。
- **审计基准**：翻译绑定以固定原版 IL/资源身份和显示消费链为依据。可写输入及地址逃逸不能作为显示目标；若原版指纹或消费链改变，须重新审计。

## 本地字体加载

Unity 5.2 不支持直接从字节加载动态字体，因此补丁将本地字体封装为对应平台的原生 Font 资源，由 Unity 生成字形和图集。

字体缓存按字体内容和模板版本区分。字体和图集跨场景复用，加载失败时按控件回退；源字体文件变更在重启游戏后生效。

## 字体设置与字号适配

- **入口与焦点管理**：设置入口的文字与点击区域共用碰撞器及原 UI 相机投影，避免坐标偏移；主菜单和游戏菜单共用设置事务。设置页独占原 UI 焦点，关闭时等待触发输入释放后再恢复焦点，场景切换时也会释放焦点。配置保存时原子替换，字号在下一帧统一刷新，字体及像素基准在重启后加载。
- **常规与 IMGUI 适配**：文字按原控件区域适配，字号计算始终基于原始尺寸，避免反复保存累乘（固定空间不保证容纳极长文本）。IMGUI 仅在显示字体或字号有差异时复制 GUIStyle；显式代码输入样式及原控件 ID、焦点和矩形保持原生行为。
- **像素字体整数倍适配**：像素字体按基准整数倍递减，并将适配后的 `UIFont` 字号同步为整数尺寸，避免二次缩放。
  - **像素标题**（`CharacterName` / `MapTitleLabel`）：保留有效像素基准并同步整数 `UIFont` 字号；普通字体及非像素缺字回退沿用原字号规则。
  - **像素正文**：沿用 12px 可读下限并向上对齐像素基准。例如开场文本 `text.1bd8ca742b1590ce` 有四行，固定版本对话框宽 561、高 90，24px 四行需要 96px 高度（旧逻辑会把 24px 字形缩放到 22px），在 12px 基准下现适配为 12px。当没有可容纳全文的可读整数尺寸时，仅当前控件回退至 Sans 普通适配，保留用户设置、按钮行和显示区域；超长文本仍受原有字号下限和行数限制。
  - **契约测试边界**：上述数值来自固定资源；`TextStyleContracts` 覆盖了四行 90px、恰好 96px、不同像素基准、即时字号变更及非像素行为，属于结构/源码契约证据，不替代实际画面验收。若对话框几何尺寸或像素基准约定改变，应重审这些适配规则。

## 设置菜单首次显示性能

原版 NGUI 每处理一种变化材质都会重新查询全部控件，放大了汉化材质排序的开销。`UIPanel.LateUpdate` 改为在单次 `Fill` 阶段内复用控件材质查询结果，返回后丢弃，下一次更新重新查询；既保留了绘制顺序、可见性检查与字体图集刷新，又不做跨帧缓存。

# 布局与渲染

`level2` Transform269 与 `level3` Transform3674 的 `MessageDialog/MessageText` 使用本地Y=-12，为中文正文保留上边距。它们与 `MapTitleLabel` 的位置无关。

`sharedassets0.assets` Material5 使用原版基准队列3000。`CW3Rendering` 为各面板的材质副本按面板、子层级Z和widget depth排序，并同步裁切材质队列；不要统一提高所有文字的队列。

NGUI的动态字体序列化绑定及两份嵌入Sans字体保留。前者使材质/图集与动态字体一致，后者为受控外部字体不可用时保留中文覆盖。样式隔离使用控件侧的UIFont副本，不修改共享原生UIFont。

默认字号和控件位置保持既有行为。可选字体与字号配置见[字体与字号](text-style.md)。


## 地图编辑器显示边界

窗口标题由 `GUIUtils.MyWindow` 的标题 Label 消费，使用独立样式副本；原有 BeginArea、回调和关闭逻辑保留。枚举选项中的 TextField 只有在返回值立即丢弃时才作为显示目标；可写名称、脚本、内部键和序列化值保持原文。编辑器竖排标签按原控件身份组成“地形”和“单位”，不改点击接收者。

绑定以固定原版 IL/资源身份和显示消费链为依据。若原版指纹或消费链改变，须重新审计；可写输入及地址逃逸不能作为显示目标。

### 本地字体的自动加载

Unity 5.2 不支持直接加载裸字体字节，因此本地字体使用按目标平台生成的 5.2.3 原生 Font 容器，字形和图集交给 Unity 管理。Mac 容器已通过离线反解析，实际加载仍需在游戏中验收。

模板只含版本锁定的元数据和空白对象。缓存按字体内容及模板版本区分，校验后原子写入；加载失败按控件回退。Font 与材质跨场景持有，图集重建刷新控件，退出时释放。字体源变化须重启加载。

### 字体设置页

设置入口的文字与点击区域共用碰撞器及原 UI 相机投影，避免坐标偏移。主菜单和游戏菜单共用设置事务。

设置页独占原 UI 焦点，关闭时等待触发输入释放再恢复；场景切换也释放焦点。配置在保存时原子替换，字号在下一帧统一刷新，字体及像素基准重启后加载。

文字按原控件区域适配，像素字体按整倍数递减；字号复用原始尺寸，避免反复保存累乘。固定空间不能保证容纳极长文本。

IMGUI 仅在显示字体或字号有差异时复制 GUIStyle；显式代码输入样式及原控件 ID、焦点和矩形保持原生行为。


像素标题（CharacterName / MapTitleLabel）保留有效像素基准，适配后的 UIFont 字号同步为整数尺寸，避免二次缩放。普通字体及非像素缺字回退沿用原字号规则。

像素正文也按基准整数倍适配，并同步最终 UIFont 字号。开场文本 `text.1bd8ca742b1590ce` 有四行；固定版本对话框宽561、高90，24px四行需要96px，旧逻辑会把24px字形缩放到22px。12px基准现在适配为12px。沿用正文12px可读下限并向上对齐基准；没有可容纳全文的可读整数尺寸时，仅当前正文控件回退Sans普通适配，不改用户设置、按钮行或显示区域。超长文本仍受原有字号下限和行数限制。

上述数值来自固定资源；`TextStyleContracts` 覆盖四行90px、恰好96px、不同像素基准、即时字号变更及非像素行为，属于结构/源码契约证据，不代表实际画面验收。对话框几何或像素基准约定改变时应重审这些适配规则。

## 设置菜单首次显示性能

旧 NGUI 每处理一种变化材质都会重新查询全部控件，放大汉化材质排序的开销。`UIPanel.LateUpdate` 在本次 `Fill` 阶段复用控件材质结果，返回后丢弃，下一次更新重新查询；保留绘制顺序、可见性检查与字体图集刷新，不跨帧缓存。

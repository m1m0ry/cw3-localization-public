# 布局与渲染依据

## 对话正文上边距

`level2` Transform 269 与 `level3` Transform 3674 都是 `MessageDialog/MessageText`。中文正文首行贴近上边框，因此将本地 Y 从 -5 调为 -12，增加上边距。具体选择 **7 单位**的量化依据未保存，标为未知；它与 `MapTitleLabel` 的位置无关。

证据为历史画面反馈与资源字段读回：v11 留存及当前安装均为 -12，源码在 `resources/layout.json` 固定该字段。没有独立验证所有字体、分辨率和对话长度。只有当前字体及布局下的对照能证明恢复 -5 后首行与边框间距仍合适，才可撤销。

## 字体材质基准队列

`sharedassets0.assets` Material 5（`Font Material`，Font756 的默认材质）从 3000 调为 3001。历史单变量试验中，仅提高队列便恢复了 Lia 中文正文可见性；将文字统一置于这一队列后，又出现菜单下层文字穿过前景的问题。

后续 `CW3Rendering` 为材质副本按面板、子层级 Z、widget depth 排序，并同步裁切材质队列。当前资源仍保留 3001，运行时副本使用 `3000 + rank`，两者不是同一层修复。历史单例及静态读回不证明固定 3001 现在仍必需；在相同运行时排序下，对照 3000/3001 的对话可见性、菜单前景遮挡和裁切均无回退，才可撤销静态调整。

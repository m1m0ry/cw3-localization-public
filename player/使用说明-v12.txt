CW3 简体中文补丁 v12
适用 Windows Steam 2.12 / build 22453699。CrossOver 使用同一 Windows Steam 游戏版本，不支持原生 Mac 版。

安装：完全退出游戏，解压后运行「安装或恢复.cmd」（Windows）或「安装或恢复.command」（CrossOver）。需要 Python 3.10+，无需额外包。安装器校验文件、备份原版，并提供恢复入口；保留 .cw3-zh-backup。
旧补丁先用旧入口恢复原版，将旧 .cw3-zh-backup 另存到游戏目录外，再安装。

手工覆盖：先备份 CW3_Data，将包内 CW3_Data 和 CW3Localization 合并覆盖到游戏目录，保留其他文件，不要整体删除文件夹。手工安装的恢复也需手工还原自己的备份，并删除新增的 CW3_Data/Managed/CW3Rendering.dll、CW3_Data/Managed/CW3Runtime.dll，以及 CW3Localization 下的 zh-CN.json、font.ttf、serif.ttf、fonts.json、text-style.json、OFL.txt、Serif-OFL.txt；恢复前另存自改词典和字体。

译文：只改 CW3Localization/zh-CN.json 的 translation，保留其他字段、标签和占位符；退出后替换，重启生效。安装和恢复不改存档。
漏译采集：创建 CW3Localization/discover.enabled 并重启即开启，删除后重启关闭；候选写入同目录 candidates.json，需人工审核，不自动翻译或上传。
文件哈希见 manifest.json，字体许可见 OFL.txt 和 CW3Localization/Serif-OFL.txt。

字体与字号
默认所有角色使用 Noto Sans SC，字号保持 100%。在游戏设置的「字体与字号」中选择并保存；字号即时生效，字体更换重启生效。自备静态 TTF/OTF 放入 CW3Localization/fonts，加载、缓存与回退由游戏完成，无需构建工具。取消不保存，恢复默认先改变草稿。缺字或加载失败时相应控件回退 Sans。代码输入保留原参数；详见「字体设置.md」。

曾用旧 Python 资源导入者，先用旧包的 font_import.py 恢复导入，再用旧安装器恢复原版；新包不携带旧导入工具或自动恢复分支。保留 .cw3-font-imports、.cw3-zh-backup 和自备字体，具体恢复步骤见「字体设置.md」。
